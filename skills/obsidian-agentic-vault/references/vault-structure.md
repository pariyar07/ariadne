# Vault Structure Reference

Use this as guidance, not a rigid schema.

## Core Folders

- `Raw/` - unprocessed captures.
- `Raw/Sources/` - source documents, links, articles, tweets, papers, repos, transcripts.
- `Notes/` - general durable notes that do not fit a specialized folder.
- `Research/` - source-backed synthesis.
- `Concepts/` - reusable ideas, models, definitions.
- `Questions/` - open questions and research prompts.
- `Decisions/` - dated decisions with context and rationale.
- `Outputs/` - generated memos, briefs, specs, slide drafts, charts.
- `Visualizations/` - Canvas files, diagrams, maps.
- `Templates/` - note templates.
- `Agent/` - workflows and local agent operating rules.
- `Bases/` - Obsidian Bases.
- `Archive/` - inactive or superseded material.

## Project Mode

Add when the vault is about shipping or building:

- `Product/`
- `Architecture/`
- `GTM/`
- `Customers/`
- `Market/`
- `Fundraising/`
- `Roadmap/`

## Research Mode

Add when the vault is about understanding a topic:

- `Literature/`
- `Papers/`
- `People/`
- `Datasets/`
- `Claims/`
- `Bibliography/`

## Learning Mode

Add when the vault is for learning a skill or field:

- `Lessons/`
- `Exercises/`
- `Examples/`
- `Practice/`
- `Glossary/`
- `Resources/`

## Life Mode

Add when the vault is for personal operations:

- `Dashboard/`
- `Goals/`
- `Areas/`
- `Health/`
- `Finance/`
- `Relationships/`
- `Journal/`
- `Admin/`
- `Resources/`

## System Mode

Add when the vault is for workflows, automations, or operating procedures:

- `Runbooks/`
- `SOPs/`
- `Automation/`
- `Tools/`
- `Logs/`
- `Checklists/`
