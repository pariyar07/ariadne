# Ingest Compile Workflow

Use this workflow when source material enters the vault.

## Source Material

Examples:

- links
- articles
- tweets
- papers
- repos
- datasets
- screenshots
- transcripts
- rough notes

## Steps

1. Capture raw/source material in `Raw/Sources/`.
2. Add metadata: title, author, URL/path, source type, accessed date, and why it matters.
3. Extract source claims.
4. Separate claims from interpretation.
5. Compile durable knowledge into the relevant folder.
6. Create or update concept notes.
7. Add wikilinks to related notes.
8. Add unresolved questions to `Questions/`.
9. Update indexes/hubs if the source changes the map.
