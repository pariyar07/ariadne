# Ariadne v0.2.0 — Research Lifecycle

`v0.2.0` is a breaking research-lifecycle release. It replaces the two older research skill names instead of shipping compatibility adapters.

Published 2026-07-15: https://github.com/pariyar07/ariadne/releases/tag/v0.2.0

## Highlights

- Adds `ariadne:research-ingest`, `ariadne:research-synthesis`, and `ariadne:research-stewardship`.
- Adds research schema v1, durable inquiries and dispositions, canonical provenance, exact/rollup boundaries, and evidence-preserving promotion.
- Adds scoped validator support and five non-fatal research counters.
- Adds deterministic behavioral contracts for authorization, provenance, synthesis, promotion, stewardship, migration, and legacy gating.

## Breaking changes

- `ariadne:research-intake` is removed. Use `ariadne:research-ingest`.
- `ariadne:synthesis` is removed. Use `ariadne:research-synthesis`.
- Old copied installation folders are not automatically deleted by every installer.

## Upgrade checklist

1. Reinstall Ariadne from `v0.2.0` for every configured agent runtime.
2. Confirm the three active research skills are installed.
3. Remove stale copied `research-intake` and `synthesis` skill folders only after confirming they are installer-managed copies.
4. Update saved prompts, commands, CI, cron jobs, launch agents, and external schedulers.
5. Compare copied weekly prompts with `ARIADNE_WEEKLY_MAINTENANCE_PROMPT_VERSION: 1`.
6. Re-sync `AGENTS.override.md` from tracked `AGENTS.md` while preserving its local marker block.
7. Run repository or installed-skill smoke tests before adopting research schema v1 in an existing vault.

Generated vaults are not migrated automatically. Schema-v1 adoption remains scope-local and opt-in.
