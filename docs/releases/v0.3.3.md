# Ariadne v0.3.3 — Routing Matrix Discovery Fix

Published 2026-07-17: [GitHub Release](https://github.com/pariyar07/ariadne/releases/tag/v0.3.3)

`v0.3.3` is a non-breaking patch release that adds a durable operational entry route to every generated scope-local task routing matrix. It does not change the scope schema or require a new adoption migration.

## Fixed

- Every generated `Agent/00 Agent Navigation.md` checkpoint now links its scope-local `Agent/Task Routing Matrix.md`.
- Scope-local routing matrices no longer appear as dangling graph leaves merely because their outgoing topology links kept them outside the strict zero-link orphan definition.
- Missing routing entry links now produce ordinary topology drift against the canonical generator and can be repaired through the authorized topology synchronizer.

## Existing Vaults

Updating installed skills does not rewrite existing vault content. For an adopted v0.3.x vault, preview and authorize a topology repair, then run scoped validation, whole-vault validation, and a second no-change synchronizer check.

## Verification

- Regression test observed failing against the pre-fix generator before implementation
- Repository and skill guardrails
- Deterministic topology, adversarial, failure-injection, recursive-scope, registration, and workspace-instruction suites
- Whole-vault dogfood validation across 15 scopes with all counters at zero
- Direct verification that all 15 routing matrices have incoming operational links
