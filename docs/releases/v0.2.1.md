# Ariadne v0.2.1 — Markdown Knowledge Vault Positioning

`v0.2.1` is a non-breaking patch release that clarifies Ariadne's core product boundary: agents operate filesystem-backed Markdown knowledge vaults directly, while Obsidian remains an optional, recommended frontend and compatibility target.

## Highlights

- Simplifies the README and quickstart to three actual requirements: a filesystem-accessible folder, Node.js with `npm`/`npx`, and a skills-capable agent runtime.
- Uses the reader-facing `ChatGPT/Codex` product label while retaining exact technical terminology where required internally.
- Aligns skill descriptions, Codex metadata, generated templates, public boundaries, and contributor/security guidance with frontend-neutral Markdown knowledge vaults.
- Updates global discovery registry and adapter wording without changing marker management, entrypoint detection, or scope authorization behavior.
- Adds a canonical 1280×640 GitHub social-preview asset.

## Compatibility

Obsidian remains an optional, recommended frontend. Obsidian-compatible wikilinks continue to be part of the file contract, and Bases, Canvas, Kanban, Dataview, and Obsidian CLI integrations remain available as optional view-layer features.

No vault migration is required. Reinstall or update Ariadne when you want the refreshed skill descriptions, generated templates, and global-discovery wording in copied installations.
