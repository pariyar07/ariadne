# Ariadne v0.3.2 — Scope Navigation and Canvas Fixes

Published 2026-07-17: [GitHub Release](https://github.com/pariyar07/ariadne/releases/tag/v0.3.2)

`v0.3.2` is a non-breaking patch release that fixes generated navigation links, adopted-scope validation, and the scope-map Canvas presentation introduced by the v0.3.x topology contract. It does not change the scope schema or require a new migration.

## Fixed

- Generated checkpoint, inheritance, map, and routing links are now path-qualified across scope boundaries. Child scopes no longer resolve root links such as `00 Index.md` or `AGENTS.md` to same-named local files.
- The validator now keeps schema-v1 canonical scope navigation separate from preserved legacy named-hub checks. Adopted scopes no longer receive duplicate or conflicting routing obligations, while canonical descriptors remain valid hierarchy anchors.
- `Agent/Scope Map.canvas` now renders one clickable text node per scope instead of stacking a label above a redundant `00 Index` file node. Scope identity stays visible and each node opens its canonical descriptor.

## Existing Vaults

Updating the installed skills does not rewrite vault content automatically. If a v0.3.x vault already generated topology artifacts, preview and authorize a normal topology repair, then run scoped validation, whole-vault validation, and a second no-change synchronizer check.

- Deterministic topology, adversarial, failure-injection, recursive-scope, registration, and workspace-instruction suites

- Second topology synchronizer check with zero findings and zero proposed changes
