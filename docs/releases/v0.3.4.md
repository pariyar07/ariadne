# Ariadne v0.3.4 — Obsidian Canvas Metadata Compatibility

Published 2026-07-17: [GitHub Release](https://github.com/pariyar07/ariadne/releases/tag/v0.3.4)

`v0.3.4` is a non-breaking patch release that prevents Obsidian-added JSON Canvas metadata from creating false topology drift or recurring repair proposals.

## Fixed

- Canvas topology validation ignores the host-owned top-level `metadata` object that Obsidian may add when opening or saving a Canvas.
- Zero-write topology repair previews use the same semantic comparison and no longer propose replacing an otherwise canonical Canvas merely because Obsidian reformatted it or recorded host metadata.
- Ariadne continues validating every generated node and edge, as well as unsupported non-host top-level fields; the exception is narrowly scoped to the known host metadata surface.

## Existing Vaults

No topology repair is required when the only difference is Obsidian's top-level Canvas metadata. Reinstall the updated skills and rerun validation; the existing Canvas may remain untouched.

## Verification

- Regression reproduced from a migrated real vault and observed failing before implementation
- Repository and skill guardrails
- Deterministic topology, adversarial, failure-injection, recursive-scope, registration, and workspace-instruction suites
- Real-vault validation with zero scope-map warnings and a zero-change synchronizer preview while preserving Obsidian metadata
